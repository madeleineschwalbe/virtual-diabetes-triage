# Changelog

All notable changes to this project are documented here.
Format loosely follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]
### Fixed
- `requirements.txt` was missing `pandas` (used by `train.py`) and `httpx`
  (required by `fastapi.testclient.TestClient`), causing every CI run to fail.
- `flake8` violations in `app/train.py` (unused import, line length).
### Changed
- `app/model.pkl` and `app/metrics.json` are no longer committed; they are
  generated by `app/train.py` and regenerated during the Docker build and in CI.

## [0.1] - 2025-10-16
### Added
- Initial FastAPI service (`/health`, `/predict`) serving a scikit-learn
  `LinearRegression` + `StandardScaler` pipeline trained on the public
  `sklearn.datasets.load_diabetes` dataset.
- Dockerfile for containerized deployment.
- GitHub Actions CI/CD pipeline: lint (flake8) + test (pytest) on every push
  and pull request, plus a Docker build/push to GHCR on release.
